# 崩塌实验室 · 自由破坏版 v8.12.0

[手机直接试玩](https://fcg-atk.github.io/skyfall-lab/) · [源码仓库](https://github.com/fcg-ATK/skyfall-lab)

面向手机浏览器的 3D 建筑破坏沙盒，支持横竖屏和电脑鼠标操作。自由模式弹药不限：选择撞击位置、切换武器，观察局部破坏、楼体倾倒和碎块撞击，直到主动重建。全部运行资源随仓库提供，无外部 CDN、账号或后端依赖。

这次发布同步本地第五版的建筑细化、连带倒塌、实体碎块与墙壁接触，并优化倒塌计算性能。碰撞几何缓存和整组空间筛选保留相同碎块数量、画质和物理子步。另修复楼体被两侧墙壁夹住后反复停在原位置、无法继续发射的问题：同时处理接触约束，并让校正位移经过实际几何碰撞检查，保留沿墙下落和墙面阻挡。

性能优化单独通过了优化前后完整回放一致性检查；双墙卡住修复另有真实状态快照回归、碰撞边界检查和实际场景自然结算检查。桌面测试不能代表所有手机设备的帧率；真实 Android/iPhone 和微信浏览器仍需实机验证。

## 操作

- 单指拖动环绕；双指捏合缩放、整体移动调整观察高度。轻点楼体瞄准。
- 「瞄准」可调整撞击高度、倾角、辅助瞄准和承重提示。
- 火箭沿列下切，陨石造成范围冲击，铁球用于精准断柱；只有实际接触才产生破坏。
- 每发倒塌稳定后可继续发射，保留废墟和得分；全毁时结算。点击「重建」恢复楼体。
- 「平衡」最高 30 FPS，「精细」最高 60 FPS，「省电」降低图形开销；档位是上限，不是性能承诺。
- 电脑也支持鼠标拖动与滚轮。音效在主动操作后启用，可随时关闭。

需要支持 WebGL 2 的现代浏览器。手机内置浏览器无法进入时，可改用系统浏览器。资源包含 gzip 副本，支持原生解压的浏览器下载约 8.3 MB 核心模型；不支持时自动回退原文件。首次加载会显示下载进度，街区纹理在后台加载。

## 本地运行与检查

安装 Node.js 22 或更新版本，无需 npm install。在仓库根目录运行：

```sh
node tools/serve.cjs
node --test tests/*.test.cjs
```

本地服务仅监听本机，终端会显示地址。测试采用真实模型及 Three.js，图形和部分浏览器对象使用替身；不能代替真实 GPU、触控事件链或手机帧率测试。碰撞性能对比测试默认跳过，避免将机器速度作为常规检查的门槛；碰撞结果一致性回归始终运行。

## GitHub Pages

向 main 推送后，现有 .github/workflows/deploy-pages.yml 会准备压缩资源、运行检查并将完整 dist/ 发布至上方试玩地址。GitHub Pages 的 Source 需要设为 GitHub Actions。静态托管也可直接使用整个 dist/；请勿只上传入口 HTML。

## 模型与许可

楼体运行时细化为 144 个结构区域，5,633 个结构和玻璃碎块、194,181 个三角形，使用两批合并网格与共享变换纹理。支撑、接触、倾倒和废墟堆积采用游戏近似；碎块之间没有逐对精确碰撞。本项目不用于建筑工程分析。
